# Tasks App

A simple Android task management application developed as a class project.

## Features

* Create and manage tasks
* View existing tasks
* Simple user interface
* Native Android application

## Technologies

* Kotlin
* Android
* Gradle
* Android Studio

## Requirements

* Android Studio
* Android SDK
* JDK

## Installation

Clone the repository:

```bash
git clone https://github.com/gMieFE/Tasks-app.git
cd Tasks-app
```

Open the project in Android Studio, sync Gradle, and run the application on an Android device or emulator.
